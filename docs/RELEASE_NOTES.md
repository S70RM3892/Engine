# 3D Engine Simulator / ENGINE EMPIRE v0.6.0

## ENGINE EMPIRE を「昼のシフト ↔ 夜のガレージ」型に作り直し

- **昼 (シフト 50 秒〜)**: ペダルでエンジンを回して稼ぐ。エンジン特性から作られる **依頼 12 種** (回転域キープ・出力テスト・レッドライン・アフターファイア・燃費・ブースト・ブリッピングなど) をこなすと ¥ と ★。熱と **耐久** があり、無理をするとブローして稼ぎ半減。**日替わりイベント** (猛暑・燃料高騰・電力ピーク・大口顧客・近所の苦情・抜き打ち検査)。
- **夜 (ガレージ)**: 結果を見て、¥ と ★ で **強化ボード** (5 系統 27 ノード)・チューン・**仕様** (高回転/低速トルク/燃費、1 台に 1 つ)・新エンジンを選んで買う。全部は買えない。次のシフトのイベント予報つき。
- **工房**: エンジンツリーの系統 (ロータリー・過給・ディーゼル・EV・航空・ジェット・蒸気) は工房を建てると開く。深いエンジンは ★ も必要。
- **目標 26 個**、夜のゼロヨン (車両ベイ)、「内部を見る」は X 線ゴーグルで解放。
- セーブ形式が変わったため、v0.5 以前のゲームの進行は引き継がれない (新規開始)。

## サウンド (v0.5 から、両アプリ共通)

- **不快な高域を除去**: ターボ・タービン翼・モータ PWM などの純音は 4kHz (モータは 2kHz) を超えないよう折り返し、マスターで 7kHz 以上を急峻にカット。17.4kHz (モスキート音の帯域) は約 −40dB。全 43 機種で 12kHz 以上の成分が最大成分より 74dB 以上小さいことを確認。
- **低音重視**: 140Hz 以下を +6dB、さらに「仮想低音」(低い点火周波数の倍音を足して、スマホのスピーカーでも太さが伝わるようにする) とバスコンプレッサを追加。
- 耳が最も敏感な 3.5kHz 付近を少し下げて刺さりを抑えた。電動機は 2kHz 以下の唸りが主役に。
- シミュレータに「低音強調」スイッチ (OFF で物理モデルの音そのまま)。

## 2 つのアプリ

| APK | アプリ名 | パッケージ | 内容 |
|---|---|---|---|
| `EngineSimulator-*.apk` | **3D Engine Simulator** | `com.s70rm3892.enginesim` | エンジン・フルシミュレーター (43 機種 + n 気筒設計、台上/MT/AT、アクセルペダル、Vulkan/GLES 描画、物理音響) |
| `EngineEmpire-*.apk` | **ENGINE EMPIRE** | `com.s70rm3892.engineempire` | 同じ物理エンジンで動くインクリメンタルゲーム (実出力 − 燃料代 = 収入、13 台のエンジン、チューン、ゼロヨン、プレステージ) |

パッケージ名が別なので両方同時にインストールでき、セーブデータも独立している。

- 対応: Android 8.0 (API 26) 以上、arm64-v8a / x86_64
- 描画: Vulkan 対応端末は Vulkan、非対応端末は OpenGL ES 3.0 に自動切替
- 既知の制約: 実機での動作確認は未実施 (ホスト上のテスト・ソフトウェア Vulkan・Robolectric で検証)。詳細はソース内の `docs/SPEC.md`

インストール: APK をダウンロード → 「提供元不明のアプリ」を許可してインストール。
